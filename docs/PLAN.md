# Согласованный план и фактический статус

Обновлено 20.10.2026. План из чата остаётся источником этапов. «Реализовано» описывает код и конкретные проверки; это не означает публикацию или полную production готовность.

| Этап | Что сделано | Что остаётся |
|---|---|---|
| 0. Требования | Мобильная архитектура, границы MVP, решения по отличиям макета, отдельное окружение Qodex | Уточнять продукт по реальным испытаниям |
| 1. Основа | Монорепозиторий, TypeScript, ESLint, lockfile, env examples и инструкции; GitHub Actions прошёл | — |
| 2. Дизайн/навигация | Нативные и web экраны, зелёная тема, карточки, формы, loading/empty/error, нижнее меню | Полное сравнение с макетом, лицензированные фотографии, нативный picker даты, расширенная accessibility QA |
| 3. БД/Auth | Шесть миграций, RLS, закрытая схема RPC, реальные Auth сессии, PKCE callbacks, SecureStore | SMTP и проверка доставки email на настоящих устройствах; production инфраструктура |
| 4. Каталог | Семей/Алматы, поиск и алиасы, категории, детали, сохранённое; 6 реальных карточек с источниками | Больше проверенного контента, этнопрограммы/операторы, медиа с правами |
| 5. Планы | Транзакционное создание, существующая/новая компания, несколько планов, версии, статусы и повторное согласие | Закрытое пользовательское тестирование |
| 6. Приглашения | Хешированные токены, лимиты/TTL/отзыв, безопасный preview, явное вступление и RSVP; проверка гонки последнего использования | Публичный домен, verified App Links/Universal Links, сценарий после установки из магазина |
| 7. Комната | Состав, владение/выход/удаление, сообщения, cursor API и история, in-app обновления | Ручное обновление выбрано для MVP; Realtime и push отдельно. Дополнить native удаление сообщений |
| 8. Бюджет | Статьи, редактирование/удаление, расчёт в тиынах, доли, устаревание и согласие с версией | Ручная QA всех действий на физических устройствах |
| 9. Карта/календарь | Внешняя карта по адресу/точке, список планов, предупреждение совпадения начала в web, ICS export и native share | Реальный календарный импорт и native предупреждения конфликтов; встроенная карта отдельно |
| 10. UGC/редакция | Черновики, события с датой, отправка на модерацию, запрет самоодобрения, правка снимает публикацию; редактор источников и аудит | Назначить реального редактора, расширить жалобы на сообщения и поток проверки медиа |
| 11. Приёмка | Unit/SQL проверки, облачные сессии и browser E2E; iOS собран и запущен в отдельном симуляторе; Android JS export | Android native build/устройство, физический iPhone, email delivery, реальные calendar clients |
| 12. Выпуск | Иконка, package IDs, EAS profiles, текст магазина и release checklist | Домен, аккаунты магазинов, signing для distribution, production review и разрешение на публикацию |

Основная вертикаль каталога → плана → приглашения → ответа → подтверждения реализована в настоящей БД. Публичный выпуск не выполнен. Непроверенные пункты остаются открытыми и не засчитываются как готовые.

См. VERIFICATION.md, RELEASE.md, DATA_SOURCES.md, DEMO_SCRIPT.md. Общий бюджет не принимает деньги; внешняя покупка билетов и синхронизация календарей не симулируются.
