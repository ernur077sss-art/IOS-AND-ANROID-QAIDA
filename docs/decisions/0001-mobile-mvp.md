# 0001 — Mobile MVP

2026-10-20. Главный клиент Expo SDK 58 / RN 0.88 / TypeScript. Next.js — браузерное приглашение и редакторский интерфейс. Общие domain/api-client пакеты. Один backend Supabase; транзакционные операции в PostgreSQL RPC, RLS для Data API. Код серверных функций не зависит от Next.js и доступен обоим клиентам.

Каталог публичный; изменения требуют Auth. Компания содержит планы. План имеет версии; существенная правка сбрасывает актуальность согласий. Приглашение: 32 random bytes, hash в БД, fragment URL, явный redeem; GET ничего не меняет. До вступления только разрешённый preview. Бюджет в тиынах bigint; деньги не принимаются. ICS — разовый экспорт.

Сначала ручное обновление комнаты; Realtime/push не обещаем. Email OTP, пользовательские имена без публичных email. Native session — SecureStore. Нет credentials: явно помеченный read-only demo каталог, закрытые операции недоступны. Нет скрытой подмены backend localStorage.

Различия с картинкой: нет выдуманных рейтингов и «приглашение отправлено» после копирования. RU/KZ не переключается на непроверенный перевод. Вход перед вступлением. Google/Apple Calendar — ICS без синхронизации. Города roadmap помечены.
